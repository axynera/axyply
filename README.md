# AxyPly

Lightweight Chrome/Edge Manifest V3 extension that automatically continues YouTube playback when the visible Continue Watching dialog appears.

## v2
- 🟢 ON/OFF toggle
- 🔢 Local continue counter
- ⏱️ Configurable click delay
- 🔔 Confirmation toast
- 🌐 English + Indonesian detection
- ⚡ MutationObserver + periodic fallback
- 🔒 No server, account, API key, or video-request modification

## Install
1. Open `chrome://extensions` or `edge://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked**.
4. Select this repository folder.
5. Open/reload YouTube.

AxyPly only automates the visible continue-watching confirmation. It does not bypass Premium, paywalls, or restricted content.
